# Savoria Bistro - Flutter Edition

This is the Flutter & Dart version of the Savoria Bistro restaurant application.

## Prerequisites
- Flutter SDK (>= 3.0.0)
- Dart SDK (>= 3.0.0)

## Getting Started

1. Navigate to this directory:
   ```bash
   cd flutter_savoria
   ```

2. Install dependencies:
   ```bash
   flutter pub get
   ```

3. Run on your connected device, emulator, or Chrome:
   ```bash
   flutter run
   ```

## Features Included
- **Home Showcase**: Hero banner, quick reservations, chef recommendations.
- **Interactive Menu**: Category filtering, search query filtering, dietary badges, add to cart.
- **Cart & Dining Modes**: Dine-in, Takeaway, and Delivery with item quantity controls and pricing breakdown.
- **Table Reservation**: Party size picker, time slots, seating area selection, and guest validation.
- **State Management**: Built with Provider pattern.
